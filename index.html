How the app organizes things

It keeps your original dump intact, then creates suggested events using dates and locations. You can rename, merge, or change anything later.

Example: add 25 Egypt photos + a few notes with “Egypt” as the location. They will appear together as an Egypt event, sorted by the dates found in the photos.

Import a social post

Paste a public Instagram, Facebook, or Threads post. The app saves the post into your scrapbook and can also save comments when Meta makes them available to the account/API you connect.

For complete comments: public oEmbed gives the post itself, not necessarily the full comment database. For posts you can access through Meta's API, add the post/media ID and access token below. The token is used only for this import and is not stored.
Meta API connection for comments
The app never writes the token to IndexedDB, backups, or the imported entry.
Fallback: paste comments if Meta does not expose them
